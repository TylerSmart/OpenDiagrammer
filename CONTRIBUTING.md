# Contributing to OpenDiagrammer

Thank you for your interest in contributing to OpenDiagrammer! We welcome contributions from the community to help make this tool the best it can be.

## How to Contribute

### 1. Report Bugs
If you find a bug, please open an issue in the repository. Include as much detail as possible, such as:
- A clear description of the bug.
- Steps to reproduce the bug.
- Screenshots or screen recordings (if applicable).
- Your environment details (OS, browser, etc.).

### 2. Request Features
We are always looking for new features and improvements. Please open an issue to describe your request and why it would be valuable to the project.

### 3. Submit Pull Requests
We love pull requests! To ensure your contribution is merged smoothly:
- **Fork the repository** and create your own branch.
- **Follow the style guidelines**: We use `.editorconfig` and `.csharpierignore` to maintain consistency.
- **Run the tests**: Ensure your changes don't break existing functionality.
- **Provide a clear description**: Explain what your PR does and why.
- **Link to the issue**: If your PR addresses a specific issue, please reference it in the description.

## Development Setup

Before you start coding, make sure you have the following installed:
- [Docker Desktop](https://docs.docker.com/desktop/setup/install/) (with WSL2 backend)
- [Visual Studio](https://visualstudio.microsoft.com/) (with .NET 10 workload)
- [Node.js](https://nodejs.org/) (for the Angular client)

Follow the instructions in the [README.md](README.md) to set up your local development environment.

## Code of Conduct
We expect all contributors to be respectful and inclusive. Please review our [LICENSING.md](LICENSING.md) for more information on our project's policies.
